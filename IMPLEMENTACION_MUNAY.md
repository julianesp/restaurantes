## 🛠️ Tecnologías Utilizadas

- **Framework:** Next.js 16 (React 19)
- **Estilos:** Tailwind CSS + SCSS
- **Íconos:** Lucide React
- **Animaciones:** AOS (Animate On Scroll)
- **State Management:** React Context API (Carrito)
- **Temas:** next-themes
- **Analytics:** Vercel Analytics

## 📱 Funcionalidades del Carrito de Compras

El sistema de carrito está **completamente funcional**:

1. **Agregar productos** desde cualquier página (menú, galería)
2. **Ver carrito** en cualquier momento (botón flotante)
3. **Modificar cantidades** de cada producto
4. **Eliminar productos** individualmente
5. **Vaciar carrito** completo
6. **Ver total** en tiempo real
7. **Proceder al checkout** con dos opciones:
   - Pago online (tarjeta/transferencia)
   - Pedido por WhatsApp
8. **Persistencia:** El carrito se guarda automáticamente
